xAPI Snippet

Configure → Copy → paste into a Rise Embed › Code block.

1 · Connection

Your worker holds the LRS credentials, so nothing secret goes into the course. Setup guide is included with the extension download.
Most secure: the snippet carries no LRS key or password at all — learners and the LMS can’t read a credential that isn’t there.
/statements is appended automatically.
Heads up: the credential is visible to learners in the embed. Use a write-only key (or a scoped, short-lived JWT), and make sure your LRS allows cross-origin (CORS) POSTs.

2 · Actor

Identifies the learner from SCORM 2004, then SCORM 1.2, then xAPI launch — whichever your LMS provides. Falls back to the actor below. Note: SCORM has no email field, so the learner ID is used unless your LMS sets it to an email.

5 · Domain restriction

Use *.example.com to allow all subdomains. Statements are skipped everywhere else — Rise preview links, staging copies, or a re-hosted package.
Leave strict off if unsure: some LMSs sandbox embeds so the domain is unreadable, and strict mode would silently drop those statements.
Note: this protects data quality, not the credential. It stops statements from copies of your course — but anyone editing their own copy can remove the check. Keep using a write-only LRS key.
